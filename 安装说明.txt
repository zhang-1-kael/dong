Dòng · 使用说明
===============

这是什么
--------
把你喜欢的视频变成 Mac 的动态壁纸：桌面在播视频，锁屏显示同一张画面。
不想找视频？直接给一条链接，下载、调优、去片尾水印、入库都自动做完。


安装
----
1. 把「Dòng」拖到左边的「应用程序」文件夹。
2. 第一次打开时，在「应用程序」里 CONTROL + 点它 → 打开 → 再点「打开」。
   这个版本没有苹果开发者签名，系统会拦一次，右键打开即可，只需一次。
3. 第一次运行会弹一个窗口问你要不要现在就把壁纸换成动态的——
   点「开始使用」它才动手，点「暂不启用」就只留一个菜单栏图标，什么都不改。
   （这个 App 的活儿就是改桌面，所以先问一句，不打招呼就换掉不太礼貌。）
4. 之后菜单栏会出现一个 ✨ 图标，点它就是全部功能。
5. 安装包里自带几个默认壁纸，第一次打开会自动放进你的壁纸库，
   点菜单栏图标 → 壁纸库 就能看到。它们跟自己加的壁纸没有任何区别：
   能删、能改名、能换掉，删掉的不会被重新塞回来。


直接给个链接（最省事）
----------------------
第一次的弹窗里、或者壁纸库右上角的「粘贴链接」，
把 B 站 / YouTube / 抖音的视频链接贴进去，点确定，剩下全自动：

    解析链接 → 下载最高可用的 1080p → 统一帧率去跳帧
    → 检查结尾有没有作者片尾卡 / 水印，有就截掉
    → 按屏幕比例裁切 → 轻微锐化 → 首尾交叉淡化做成无缝循环
    → 压缩 → 生成封面 → 加入壁纸库 → 立刻设成当前壁纸 → 同步锁屏

进度会显示在壁纸库底部的小胶囊里。一条 20~30 秒的视频，通常 20~60 秒处理完。
注意：B 站 4K / 60 帧需要大会员，普通账号只能拿到 1080p，这是平台限制。


片尾水印会自动截掉
------------------
很多视频最后 2~5 秒是「XX 壁纸推荐」这类片尾卡，上面带着作者名和平台 logo，
当壁纸循环播放时每转一圈就会闪一次，很出戏。

现在导入时会自动分析结尾一段画面的运动量：发现结尾有一次硬切、
切完之后画面基本不动（就是那种静帧片尾卡），就把这一段连同水印一起截掉，
再从截断处做首尾淡化接成循环。

判断是保守的——如果结尾还在正常播放画面，就不动它。
想确认某条有没有被截，可以看壁纸库里鼠标悬停时显示的时长。


点状态栏图标会弹出什么
----------------------
左键点状态栏图标，弹出一个自己的小面板（不是系统那种灰菜单）：

  顶部        「Dòng」大标题，右边是「退出」；
              标题下面一行小字：壁纸张数 · 磁盘占用 · 在线时长
  壁纸库      一条通栏的浅底按钮，点它进大图瀑布流（三个开关也在里面）
  正在使用    大封面 + 右边的名字，名字下面一行「1726×1080 · 23 fps · 31S」；
              再下面一行是「正在使用」
  其他壁纸    最下面一排缩略图，是除当前这张以外的所有壁纸，
              左右滑（触控板双指 / 滚轮 / 按住拖）能看完全部，点哪张换哪张

面板外随便点一下、或者按 ESC 就收起。

右键点状态栏图标，仍然给出原来的系统菜单（带 ⌘, ⌘Q 快捷键和
「展开其余 N 条…」折叠列表），习惯用键盘的话可以走这条。


壁纸库
------
打开是一面瀑布流照片墙，没有别的按钮：

  · 把视频文件（mp4 / mov / m4v）拖进窗口 = 自动导入并加入壁纸库。
    也可以一次拖多个。导入时会自动优化：统一帧率、按屏幕比例裁切、
    轻微锐化、截掉片尾水印、首尾交叉淡化做成无缝循环、压缩体积。
  · 鼠标悬停在卡片上 = 这段壁纸当场动起来播放，同时浮出名字、大小和时长。
  · 点一下卡片 = 立刻换成这张壁纸，卡片左上角会标上「正在使用」。
  · 卡片右上角的 × = 删除（文件移到废纸篓，不是硬删）。
  · 右键卡片 = 设为壁纸 / 在访达中显示 / 删除。
  · 页面右上角有两个极淡的小字：「粘贴链接」「打开文件夹」。
    第一个读剪贴板里的视频链接，自动下载 + 优化 + 入库；
    第二个直接在访达里打开壁纸文件夹。
  · 右上角齿轮（浮在右上角那个小圆钮）里只剩三个开关：
      启用动态壁纸      总开关。关掉 = 桌面视频撤掉，恢复系统壁纸。
      锁屏跟随当前壁纸  见下面「锁屏」一节。
      开机自动启动      登录时自动运行。
  · 关掉程序再打开，会接着用上次选的那条；窗口大小和位置也会记住。
  · 壁纸超过 10 条时，右键出来的系统菜单只显示前 10 条，
    末尾有「展开其余 N 条…」，点开看全部；左键的面板不受这个限制。


锁屏
----
桌面播的是视频；锁屏显示的是同一段视频的一帧（静止画面）。

为什么锁屏不能动：macOS 的锁屏只认苹果自己签名过的「航拍」素材，
第三方 App 把视频塞进锁屏会直接被系统回退成自带风景图（这条已经实测过）。
所以这里做的是「同一个场景」：解锁前看到的那张画，就是你桌面视频里的画面。

不想要：齿轮里取消勾选「锁屏跟随当前壁纸」。


系统要求
--------
macOS 13 或更新，建议 Apple 芯片（随包的 ffmpeg 和 yt-dlp 是 arm64 版）。
处理视频、解析链接用的都是 App 内置的组件，不需要另外安装任何东西。


常见问题
--------
· 桌面没变化？
  齿轮里看「启用动态壁纸」是否没开；或者点一下面板里的任意一张缩略图。
· 链接下载失败？
  可能是需要登录才能看的视频（会员专享、付费课程），或者链接不是单个视频
  （合集、直播）——这类只能先自己下载成文件再拖进来。
· 某个视频导入失败？
  多半是不支持的封装（.avi / .wmv / .mkv），先转成 mp4 再拖进来。
· 片尾水印没被截掉？
  说明检测没把握（比如片尾是动态画面，或者水印压在正片里没换镜头），
  这种情况宁可不截也不误伤。可以先自己剪掉再拖进来。
· 画面上一直有个角标 / logo？
  那是压进画面的水印，不在结尾，属于另一个问题（要打码就得固定位置擦除，
  会把那一小块画面糊掉）。目前不自动处理。
· 会不会费电 / 吃内存？
  主程序常驻约 15 MB 内存（打开壁纸库浏览封面时约 35 MB），
  视频解码另有一个系统进程（VideoToolbox）约 90 MB。
  用电池时可以在齿轮里关掉「启用动态壁纸」。
· 壁纸存在哪？
  ~/Library/Application Support/VideoWallpaper/wallpapers
  封面缓存在同目录的 gallery 文件夹，删掉会自动重建。


卸载
----
菜单 → 退出 Dòng → 把 App 删掉。
先在齿轮里关掉「开机自动启动」，再删。
壁纸库在 ~/Library/Application Support/VideoWallpaper，可以整个删除。
