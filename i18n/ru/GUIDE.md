# Dòng — Техническое описание и проект

> Вся остальная информация о проекте на русском языке.

## Архитектура

Четыре независимых конвейера: окна на слое рабочего стола с `AVPlayerLayer`, перекодирование yt-dlp + ffmpeg, нарисованные вручную панель строки меню и библиотека на AppKit, а также автозапуск / наблюдение за папками / анонимная статистика через LaunchAgent.

## Ключевые детали реализации

- Каждое окно на 24 pt больше экрана, чтобы скрыть скруглённые углы и кромки при смене рабочего стола.
- Подпись `--deep` ломает вложенные подписи ресурсов — не используйте её.
- Звук для цикла микшируется тремя отдельными перемотками; при одной остаётся щелчок.
- Панель строки меню целиком рисуется вручную, чтобы перекрыть системное матовое стекло.

## Отладка из командной строки

```bash
VideoWallpaper --detect a.mp4
VideoWallpaper --try a.mp4 out.mp4
VideoWallpaper --import a.mp4 b.mp4
VideoWallpaper --link "https://…" 
```

Переменные окружения (`VW_PANEL_SHOT`, `VW_GEOM`, `VW_DUMP_MENU`, …) перечислены в разделе 9 китайского оригинала.

## Участие и политика по ИИ

## Приватность

Анонимная статистика включена по умолчанию и отключается в настройках. Если вы делаете форк, задайте `isEnabled` в `Analytics.swift` значение `false` по умолчанию.
